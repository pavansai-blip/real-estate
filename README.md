# ESTORA Real Estate Demo Website

A responsive front-end prototype built with HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Features
- Home, Buy, Rent, Projects, About, Saved, Contact and List Property views
- Search and property filters
- Sort listings
- Property detail pages
- Favorites persisted in localStorage
- Demo forms and toast feedback
- Responsive layouts

## Notes
Listings, testimonials, project details and contact details are fictional demo data. Images are remote Unsplash images. This is a front-end prototype; forms do not submit to a backend.
